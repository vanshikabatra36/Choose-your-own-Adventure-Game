# 🗺️ Text Adventure Game

A simple **text-based adventure game** built with Python. The player explores different paths, makes choices, and experiences different outcomes based on their decisions.

## 🎮 How It Works

1. Enter your name to begin the adventure.
2. Start on a dirt road and choose between going **left** or **right**.
3. Each choice leads to a new situation.
4. Continue making decisions to progress through the story.
5. Your choices determine whether you **win or lose**.

## ✨ Features

* Interactive text-based gameplay
* Player name input
* Multiple decision paths
* Different endings
* Input validation
* Nested conditional statements
* Story-driven gameplay

## 🛠️ Technologies Used

* **Python 3**

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/vanshikabatra36/Choose-your-own-Adventure-Game.git
```

2. Open the project folder in your terminal.

3. Run the program:

```bash
python adventure_game.py
```

4. Follow the instructions and make your choices.
